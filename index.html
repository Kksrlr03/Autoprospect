Connect Google Places

Paste your own Google Maps Platform API key. It is kept in this tab's memory only and sent directly from this browser to Google Places. It is not stored in browser storage, included in GitHub files, or sent to an app server. Enable Places API (New), restrict the key to that API and to your GitHub Pages website referrer. Every friend enters their own key in their own browser.

A key authorizes requests; it does not make them free. Each page returns up to 20 places and Next 20 makes another search request. Restrict the key to your site origin (for example https://YOUR-USERNAME.github.io) and Places API (New). The key is cleared when this tab closes or refreshes. “Without a listed website” requests website data during search.
